# Featured Projects

## Air Quality Batch Processing Pipeline

**Python · Pandas · MongoDB · Docker · Data Engineering**

A containerized data engineering pipeline for processing more than **700,000 hourly air-quality measurements** from multiple cities.

The pipeline organizes the source data into **daily batches**, performs cleaning and validation, loads processed records into MongoDB, and provides batch monitoring, city-level summaries, and AQI-oriented outputs.

Key engineering concepts demonstrated:

* Daily batch-processing workflow
* ETL pipeline design
* Data cleaning and validation
* MongoDB persistence
* Retry-safe and idempotent loading
* Batch monitoring and logging
* City-level aggregation
* Dockerized execution
* Automated testing

**Repository:**
https://github.com/myingineer/data-engineering-air-quality-batch-pipeline

## Smart Factory Predictive Maintenance

**Python · Machine Learning · FastAPI · Industrial AI**

A predictive-maintenance and anomaly-detection system designed for industrial electric motors in a smart manufacturing environment.

The system processes simulated machine telemetry including temperature, vibration, pressure, humidity, and energy consumption. A trained machine-learning model evaluates equipment conditions and exposes predictions through a FastAPI service.

Key features:

* Industrial sensor-data simulation
* Machine-learning anomaly detection
* Random Forest classification
* Real-time prediction API
* Equipment risk scoring
* Maintenance recommendations
* Prediction logging
* Industrial AI use case
